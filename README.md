# CGAC Website — Ministry Archive and Digital Platform

This repository contains the CGAC (Christ Gospel Apostolic Church) digital ministry platform: a production-ready website and administrative dashboard focused on the Ministry Archive (programmes, conventions, watchwords, sermons, media, and giving).

This project follows a modular MVC PHP architecture with MySQL and PDO.

See docs/ for detailed design, architecture, database schemas, and the implementation plan.
